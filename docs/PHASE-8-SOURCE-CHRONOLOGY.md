# Phase 8 — source chronology

**Status:** Implemented in the intent-first workspace.

The chronology displays only dates supplied by source metadata or workspace records: publication, retrieval, workspace save, and link-reachability check. The UI labels each event type independently and does not infer an underlying event date from publication or retrieval metadata.

Invalid or missing dates are omitted rather than guessed. A reachability check is a time-bounded observation and does not establish whether a source is accurate or safe.
