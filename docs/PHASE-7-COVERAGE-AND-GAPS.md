# Phase 7 — coverage and research gaps

**Status:** Implemented in the intent-first workspace.

The coverage snapshot reports source count, distinct hostnames, represented provider names, records with multiple explicit provider matches, missing publication dates, and missing publisher labels. It also surfaces prompts for additional research when the current result set is concentrated or metadata is incomplete.

These are descriptive coverage indicators, not source credibility signals. Different hostnames do not prove independent ownership, and multiple provider matches do not prove independent corroboration.
